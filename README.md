# Leave Management System - Backend

A role-based REST API for managing **college student leave requests** through a multi-level approval workflow (Mentor → HOD → Warden). Built with **Java 17, Spring Boot 3, Spring Security (JWT) and MySQL**.

## Features

- **JWT authentication** with stateless sessions and BCrypt password hashing
- **Role-based access control** for six roles: `STUDENT`, `MENTOR`, `HOD`, `WARDEN`, `CHIEF_WARDEN`, `ADMIN`
- **Multi-stage approval workflow** with a full approval history for every request
  - Hostellers: Student → Mentor → HOD → Warden
  - Day scholars: Student → Mentor → HOD
  - Remarks are mandatory when rejecting; a rejection at any stage ends the request
- **Auto mentor assignment** based on the student's department section and year
- **Warden dashboard** with block-wise leave requests and room occupancy view
- **In-app notifications** (list, unread count, mark as read)
- **Asynchronous email notifications** to approvers using Spring Mail with `@Async`
- **Audit logging** of key actions (who did what, on which entity, and when)
- **Admin user management** (create, view, update, delete) for students, mentors, HODs and wardens
- **Input validation** using Bean Validation, including a custom date-range validator
- **Centralized exception handling** with `@ControllerAdvice` and custom business exceptions
- **Swagger / OpenAPI** documentation
- **Rolling log files** using Logback

## Architecture

Layered structure under `com.college.leavemanagement`:

```
controller/   REST endpoints (Auth, Student, Mentor, Hod, Warden, Admin, Notification)
service/      Business logic and workflow rules
repository/   Spring Data JPA repositories
entity/       JPA entities
dto/          Request and response objects
mapper/       MapStruct mappers
security/     JWT filter, JWT utility, user details
config/       Security, Swagger, async and startup configuration
validation/   Custom validators
exception/    Global exception handler and custom exceptions
enums/        Role, LeaveStage, ApprovalStatus, StudentType, etc.
```

### Main entities

`User`, `Student`, `Mentor`, `Hod`, `HodDepartmentAssignment`, `Warden`, `LeaveApplication`, `ApprovalHistory`, `Notification`, `AuditLog`

## Leave Workflow

```
Student submits leave
        │
   MENTOR_REVIEW ──reject──► REJECTED
        │ approve
    HOD_REVIEW ───reject──► REJECTED
        │ approve
        ├── Day scholar ──► COMPLETED (Approved)
        │
  WARDEN_REVIEW ──reject──► REJECTED     (hostellers only)
        │ approve
    COMPLETED (Approved)
```

## API Overview

The API exposes 50+ endpoints. Full interactive documentation is available in Swagger UI once the app is running.

| Role | Base path | Main operations |
|------|-----------|-----------------|
| Public | `/auth` | `POST /auth/login` |
| Student | `/student` | View profile, submit leave, view leave history |
| Mentor | `/mentor` | View/search students, list pending requests, approve/reject, leave history |
| HOD | `/hod` | Manage departments, students and mentors, approve/reject, leave history |
| Warden / Chief Warden | `/warden` | Hostel students, approve/reject, leave history, room occupancy, manage wardens (Chief Warden/Admin) |
| Admin | `/admin` | CRUD for students, mentors, HODs and wardens; view audit logs |
| Any logged-in user | `/notifications` | List notifications, unread count, mark as read |

## Getting Started

### Prerequisites
- Java 17+
- Maven 3.8+
- MySQL 8+

### Setup

1. Clone the repository
   ```bash
   git clone https://github.com/praveen12-19/Leave-Management-System-Backend.git
   cd Leave-Management-System-Backend
   ```

2. Configure `src/main/resources/application.properties`
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/leave_management_db?createDatabaseIfNotExist=true
   spring.datasource.username=<your_db_username>
   spring.datasource.password=<your_db_password>

   jwt.secret=<a_long_random_secret_key>
   jwt.expiration=86400000

   spring.mail.username=<your_email>
   spring.mail.password=<your_app_password>
   ```
   The database is created automatically if it does not exist, and tables are generated by Hibernate.

3. Run the application
   ```bash
   mvn spring-boot:run
   ```

4. Open the API docs at `http://localhost:8080/swagger-ui.html`

> A default admin account is created on first startup. Change its password immediately after logging in.
